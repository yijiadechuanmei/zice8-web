# 活动图片资源

图片统一由 `assets.js` 导出。后续上传 OSS 后，只替换该文件中的四个 URL，不改页面结构或交互。所有资源位于本活动 `assets/` 下，已压缩为 WebP。

| 文件 | 用途 | 配置字段 |
| --- | --- | --- |
| `assets/home.webp` | 首页竖屏背景、盾牌与家庭插画 | `assets.home` |
| `assets/quiz.webp` | 三关答题、成功页、登记页与记录页背景 | `assets.quiz` |
| `assets/wheel.webp` | 转盘页面背景与光环 | `assets.wheel` |
| `assets/prizes.webp` | 背包、防晒帽、抱枕被三件奖品图 | `assets.prizes` |

通过内置图片生成工具生成，参考了所提供横版主视觉的浅粉、红金丝带、盾牌、家庭和天平元素，重新构图为竖屏；奖品图为三件产品单独展示。最终提示词分别要求竖屏活动首页背景、留有答题空间的通用背景、留有转盘空间的光环背景、三件奖品的方形展示图，均明确要求无文字、Logo、标识及水印。转盘扇区与按钮由 HTML/CSS 绘制，实际结果来自服务端。
